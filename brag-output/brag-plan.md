# Brag Plan: Frimz

## What is this app?
An AI thinking partner that remembers how an idea evolved and turns that context into something the user can keep building on.

## The angle
polished

## Hook
Positioned as a thinking partner that does not decide for the user, keeps the durable path of an idea, and makes later work continuable.

## Key moments (the middle)
- Show the real Frimz interface — landing UI.
- Authenticate → POST /api/chat with message and optional mode → Create or load a conversation → Persist the user message unless retrying → Resolve or attach the current idea → Recall memories and preferences → Load the idea brief if one exists → Choose a conversation strategy and stream tokens → Emit done with optional indicators and draft metadata
- The primary product loop is an authenticated SSE chat turn that binds an idea, memory, and brief before streaming a strategy-guided reply.

## Outro / punchline
Frimz
