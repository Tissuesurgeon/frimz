# Demo

Use a real account on the deployed app. Do not prepare the database first.

## Workflow

1. Create an account.
2. Start a real conversation.
3. Develop an idea across the chat.
4. Make a decision in your own words.
5. Reject a direction in your own words.
6. Leave and come back in a new conversation.
7. Ask Frimz to continue the idea.
8. Ask why a direction was rejected.
9. Ask how the idea arrived where it is.
10. Open Memory, then edit or forget something you actually want changed.

## Acceptance

Memory is doing real work only if the later conversation is different because of stored context.

```text
WITHOUT the prior memory
  The reply has to ask which idea you mean.

WITH Frimz recall
  The reply continues the actual idea
  It can explain a stored rejection
  It can answer how the idea evolved from stored events
  When a working-style preference exists, the reply follows it
```

If the history does not contain a step, Frimz should say it does not have that step. Do not fill a missing step for the recording.

## Before recording

Confirm the memories on screen were extracted from the conversation you are about to show. Confirm the other person's permission if their words will be published.
