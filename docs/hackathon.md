# Hackathon

Frimz is an AI thinking partner that remembers the evolution of your thinking and turns that accumulated context into something you can continue building on.

Its memory is supposed to make a later conversation better. Walrus Memory is the semantic store behind that behavior: it lets Frimz carry meaningful context from earlier conversations into later thinking.

## The story

```text
CONVERSATION
     ↓
THINKING
     ↓
MEMORY            durable decisions, set-aside directions, insights, and open questions in Walrus
     ↓
CONTEXT BRIEF     a living, versioned picture of where each idea stands
     ↓
CONTINUITY        the next conversation starts from the brief and the recalled memories
     ↓
FURTHER THINKING
     ↓
STRUCTURED OUTPUT a draft written from the accumulated context, when the user wants one
```

Walrus Memory carries the pieces across sessions. The context brief holds them together as one picture the user can read and correct. A later conversation starts from both, so the thinking continues where it left off. When the user wraps up, Frimz offers to turn the accumulated context into a project brief, a proposal, or another fitting format.

## What the product demonstrates

- A real account starts empty
- Meaningful memories are extracted from conversations, not typed in by an operator
- Those memories live in a per-user Walrus namespace
- Each idea gets a context brief, built from those memories and the conversation, that updates as the thinking moves
- Frimz keeps the user's decisions separate from its own suggestions, and the latest user direction wins
- A later session can continue an idea, explain a rejection, and describe how the idea changed
- The user can inspect, edit, and forget memories, and edit or regenerate the brief
- A wrap-up can turn the accumulated context into a written draft

## Requirements still collected after deployment

Do not fill these with invented numbers.

- Public GitHub repository
- Public deployment URL
- At least three real people using their own accounts
- At least ten meaningful memories for each of those people, created by their conversations
- More than one session per person
- A later turn that uses a recalled memory and the idea's current thinking
- A memory update or supersede from a real change of mind
- A context brief that changed version because of a real change of direction
- An idea timeline from real idea events
- Screenshots or a recording of those actual threads
- Permission from each person before publishing their words

## What this repository does not contain

No seed users, seed conversations, seed memories, seed context briefs, demo account, fake testimonials, or fake usage totals.

Unit-test fixtures under `tests/` are not production data. The landing page illustrations are labelled as illustrations.
